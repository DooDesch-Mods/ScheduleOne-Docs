## Before you start

- Every library is optional for your players. [Call another mod's API](/using-a-mod-api/) shows how your mod keeps working without it.
- Each library has an API reference with every type and member. Open it from the library's page in the sidebar.
- A coding agent can read the same API. See [Use with an AI agent](/agents/).
