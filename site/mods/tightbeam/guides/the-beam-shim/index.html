The Beam shim (`TightBeam.cs`)

Copy this single file into your mod project (namespace TightBeam.Api). It is Unity-free, has no dependencies, and every call is a no-op when TightBeam is not installed - so you can ship it unconditionally. See the Modder API for how to use it. (Or reference TightBeam.Api.dll instead of copying.)
